# SC-300 and IAM Skills Mapping

## Purpose

This document connects Project 1 to Microsoft Identity and Access Administrator learning areas. It records practical evidence without claiming that one project covers the entire SC-300 exam.

## Current project coverage

| SC-300 area | Project 1 evidence | Coverage |
| --- | --- | --- |
| Implement and manage user identities | User lifecycle planning, groups, licensing, hybrid source-of-authority decisions | Introductory practical |
| Implement authentication and access management | Graph token acquisition, account disablement, session revocation, audit review | Introductory practical |
| Plan and implement workload identities | Managed identity, Azure Automation, application permissions, `DefaultAzureCredential` | Introductory practical |
| Plan and automate identity governance | Joiner–mover–leaver controls, managed groups, audit evidence, safety limits | Introductory practical |

## Skills demonstrated

- Microsoft Entra ID user and group concepts
- Microsoft Graph REST operations
- Microsoft Graph PowerShell
- Azure Identity token acquisition
- Delegated versus application authentication concepts
- Managed identities and workload identity selection
- Cloud-only versus synchronized source of authority
- Group-based licensing design
- Offboarding and access removal
- Structured execution audit logging
- Dry-run, idempotency, and fail-closed safety controls

Use careful wording such as:

Do not claim that this project alone demonstrates complete SC-300 readiness or production IAM expertise.
